Neural Speech Denoiser — Listening Test

English｜中文

取自公開 VCTK-DEMAND 測試集的五段含噪語音，由編譯後的 C 函式庫以三種模型寬度降噪。所有音檔皆為16 kHz 單聲道；降噪後的音檔是函式庫 int16 串流路徑的實際輸出（抑制強度 1.0），比輸入晚一個 16 ms 幀，與裝置上的執行結果完全相同。建議戴耳機聆聽，並與每張卡片最後一列的乾淨錄音室原音比較。

客觀評測

我們的完整尺寸模型與已發表的輕量級即時降噪模型並列。DNS OVRL 分數取自各模型自己的論文，並非在同一測試集上量測，僅供量級參考。

試聽音檔

每段音檔的 DNSMOS（無參考）與相對乾淨原音的 SI-SNR，皆直接以播放器背後的檔案計算；SI-SNR 在扣除函式庫的一幀延遲後量測。 五段平均 — OVRL：含噪 2.76 → W16 2.89 · W12 2.95 · W8 + KD 2.88（乾淨原音 3.23）；SI-SNR：含噪 10.4 dB → W16 15.8 · W12 16.3 · W8 + KD 15.6 dB。
